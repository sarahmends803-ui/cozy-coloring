Cozy Pastel Coloring Studio (installable app), made by Tablu

1. Put every file in this folder on any free HTTPS web host, keeping them together
   in the same folder (for example GitHub Pages, Netlify or Cloudflare Pages).
   Apps can only be installed from an https:// address, not from a file on the device.
2. On your Android tablet, open that address in Chrome.
3. Tap "Install app" in the page header, or Chrome's menu > "Install app" / "Add to Home screen".
4. Open it from the home screen. It runs full screen and works offline after the first visit.

Your pictures and projects are stored on the device inside the app. Clearing the app's
data or uninstalling it can erase them, so use "Back up my library" in My Coloring Library
now and then.
